[![Android](https://img.shields.io/badge/Platform-Android-3DDC84?style=flat-square&logo=android&logoColor=white)](https://developer.android.com)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-UI-4285F4?style=flat-square&logo=jetpackcompose&logoColor=white)](https://developer.android.com/jetpack/compose)

**NS Vault** is a secure, user-friendly, and offline-first personal data manager for Android. It allows you to safely store all your sensitive information—such as passwords, financial cards, notes, and private links—in one centralized place protected by robust encryption and biometric security.

---

## 📥 Download & Installation

You can download the latest signed APK directly from the **[Releases](../../releases)** page:

1. Go to the **[Releases](../../releases)** tab of this repository.
2. Download the latest signed `.apk` file (`app-release.apk`).
3. Tap the downloaded file on your Android device to install (you may need to allow installation from unknown sources if prompted).
4. Open **NS Vault** and enjoy secure, offline-first personal data management!

> **Note:** New updates, features, and security patches will be published regularly via GitHub Releases. Watch or star the repository to stay notified of updates!

---

## ✨ Key Features

- **🔒 Secure Storage**: Safely store credentials, financial details, private notes, and important links with advanced encryption.
- **🔑 Password & PIN Generator**: Instantly create strong, customizable passwords and secure numeric PINs.
- **🗑️ Trash & Recovery**: Easily manage deleted items with options to restore them when needed or clear them permanently.
- **🧬 Advanced Security**: Protect your vault using biometric authentication (fingerprint/face unlock) and master PIN protection with customizable auto-lock timeouts.
- **💾 Data Backup & Restore**: Centralized full-app encrypted export and import capabilities accessible directly from settings.
- **⚡ Configurations & Pagination**: Manage vault configurations with built-in pagination and adjustable batch sizes.

## 📖 How to Use

1. **Setup**: On first launch, set up your master PIN and enable biometric unlock for quick, secure access.
2. **Add & Manage**: Organize and manage your private records across different categories using the intuitive interface with automatic A-Z sorting.
3. **Generate Security Keys**: Use the built-in generator to create strong passwords and PINs whenever needed.
4. **Customize Settings**: Adjust security preferences, theme appearance, auto-lock timeouts, and backup options from the modern settings menu.
